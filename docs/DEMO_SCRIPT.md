# Week 1 demo video script (about 90 seconds)

Screen-record the browser at http://localhost:3000. Speak over it.

**0:00 – Hook (hero)**
"This is Tollgate, a research agent with its own wallet. It tries free sources first, shows every step, and later this month it will pay for premium data over x402, within limits you set."

**0:10 – Setup (console)**
Point at the status lights. "Three services: Next.js front end, a Node backend, and a Python agent." Click **Create wallet**. "That's a Base Sepolia testnet wallet. The key never leaves the backend."

**0:25 – Prompt 1: tools in action**
Ask: `Price of ETH and BTC right now, and how did they move today?`
While it runs: "It picked the crypto price tool by itself." Click the tool step to expand. "I can see exactly what it sent and what came back."

**0:45 – Prompt 2: multi-tool research**
Ask: `What is x402 and why does it matter for AI agents?`
"Search, then it reads a page, then answers with source links and a confidence label." Point at the **Paid-source signal**. "This tells us when a premium source would improve the answer. That's the hook for Week 2."

**1:05 – Prompt 3: wallet**
Ask: `What is in your wallet?` "The agent can report its own balances."

**1:15 – Model switch**
Change the model in the dropdown and run a quick question. "Gemini or Claude, switchable per question."

**1:25 – Close (roadmap)**
Scroll to the roadmap. "Week 2: buy-or-skip logic. Week 3: real x402 payments. Every cent itemised."
